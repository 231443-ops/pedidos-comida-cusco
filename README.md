# Pedidos de comida local en Cusco

## Descripción
Proyecto académico basado en el caso de una startup de Cusco que desea desarrollar un sistema web para gestionar pedidos de comida local.

## Objetivo del laboratorio
Configurar el entorno de desarrollo y utilizar Git para organizar el proyecto y registrar sus versiones.

## Herramientas
- Visual Studio Code: edición de archivos.
- Git: control de versiones.
- GitHub: alojamiento del repositorio remoto.

## Estado actual
El proyecto se encuentra en la etapa de configuración inicial y documentación.
